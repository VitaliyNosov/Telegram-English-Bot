# Техническое задание (ТЗ) — Итерация 1: Начальная разработка
## Проект: English Telegram AI Mini App (Duolingo Style)

---

### 1. Видение и концепция продукта

**English Telegram AI Mini App** — это интерактивное веб-приложение (Telegram Mini App) в жизнерадостной, дружелюбной стилистике (a-la **Duolingo**), предназначенное для живой разговорной практики и изучения английского языка с помощью искусственного интеллекта от Google (Gemini) и синтеза речи.

#### Ключевые преимущества:
1. **Zero-Backend / Архитектура BYOK (Bring Your Own Key)**:
   - Пользователь вводит свой собственный Google Gemini API ключ в настройках приложения.
   - Ключ хранится локально в `localStorage` / Telegram CloudStorage устройства пользователя.
   - Нулевая стоимость серверной инфраструктуры, приватность запросов, отсутствие риска превышения общего лимита.
   - При исчерпании лимитов или смене аккаунта пользователь в один клик меняет ключ в настройках.
2. **Хостинг на GitHub Pages**:
   - Статическое приложение (HTML5 / Vanilla JavaScript / Modern CSS) разворачивается прямо в публичном репозитории через GitHub Pages.
   - Нативный HTTPS из коробки (обязательное требование для Telegram Mini Apps и микрофона/Web Speech API).
3. **Мультимодальность (Текст + Голос)**:
   - Синтез речи бота: британский и американский акценты, мужские и женские голоса.
   - Голосовой ввод пользователя (Speech-to-Text) для тренировки живого произношения.

### 2. Дизайн и визуальный стиль (Duolingo-инспирация)

- **Цветовая палитра**:
  - Фирменный зеленый Duolingo (ярко-зеленый `#58CC02`, сочный темнее для 3D-кнопок `#46A302`).
  - Акцентные цвета: солнечный желтый (`#FFC800`), небесно-голубой (`#1CB0F6`), кораллово-красный (`#FF4B4B`), фиолетовый (`#CE82FF`).
  - Фоны: чистый светлый (`#FFFFFF` / `#F7F7F7`) и стильный темный режим (`#131F24` / `#1B2A32`), гармонирующий с темой Telegram.
- **Типографика и элементы**:
  - Круглые, дружелюбные шрифты (например, *Nunito*, *Outfit* или системные скругленные).
  - «Пухлые» тактильные 3D-кнопки с эффектом нажатия (active press effect).
  - Карточки с мягкими скруглениями (16–20px), легкие тени, анимации всплытия и конфетти при успехе.
  - Маскот / бейджики настроения бота, индикаторы прогресса (streak / серия дней, XP или кристаллы).

### 3. Функциональные требования: Итерация 1

#### 3.1. Экран настроек (Settings / API Configuration)
- **Поле ввода Google Gemini API Key**:
  - Маскирование ключа (`••••••` с возможностью показать/скрыть).
  - Кнопка **«Проверить подключение» (Test Connection)**: отправка тестового легковесного пинга в Gemini API.
  - Статус валидности ключа: зелёный бейдж при успехе, понятное объяснение ошибки (например, `429 Quota Exceeded` или `Invalid API Key`).
  - Ссылка-подсказка, как бесплатно получить ключ в Google AI Studio за 1 минуту.
- **Выбор модели Gemini**:
  - Селектор моделей: `gemini-2.5-flash` (по умолчанию, самая быстрая и умная), `gemini-2.0-flash`, `gemini-1.5-flash`, `gemini-1.5-pro`.
- **Настройки голоса (Text-to-Speech)**:
  - Выбор акцента: American English (US) / British English (UK).
  - Выбор голоса: женский / мужской.
  - Тумблер автовоспроизведения (Auto-play voice on reply).
  - Скорость воспроизведения (0.8x для новичков, 1.0x нормальная, 1.2x быстрая).
- **Уровень владения английским (CEFR)**:
  - Выбор: A1–A2 (Beginner / Elementary), B1–B2 (Intermediate), C1–C2 (Advanced).
  - В зависимости от уровня промпт бота адаптирует словарный запас и сложность фраз.

#### 3.2. Экран диалога (Chat & Practice)
- **Интерактивный чат**:
  - Сообщения пользователя и ответы бота.
  - Кнопка озвучки 🔊 у каждого сообщения бота.
  - Кнопка перевода / подсказки.
- **Блок обратной связи по грамматике (Grammar & Vocabulary Feedback)**:
  - Под каждым сообщением пользователя бот может аккуратно подсветить:
    - *Is it correct?* (Отлично / Можно улучшить).
    - *Better way to say:* более естественный вариант фразы (idiomatic expression).
- **Голосовой ввод (Microphone / STT)**:
  - Кнопка микрофона в строке ввода: запись речи, отображение транскрибированного текста с возможностью отправки.
- **Сценарии и темы (Topic Selector)**:
  - Быстрый выбор темы разговора в верхней панели или карусели:
    - ☕ *At the Coffee Shop* (Заказ кофе и выпечки)
    - ✈️ *At the Airport / Travel* (Регистрация, паспортный контроль)
    - 💼 *Job Interview* (Собеседование на английском)
    - 💬 *Casual Small Talk* (О погоде, хобби, планах)
    - 🩺 *Grammar Clinic* (Разбор сложных грамматических правил)

#### 3.3. Интеграция с Telegram WebApp
- Подключение скрипта `telegram-web-app.js`.
- Инициализация `window.Telegram.WebApp`:
  - `expand()` — разворачивание приложения на весь экран.
  - Поддержка темной и светлой темы согласно настройкам Telegram.
  - Тактильный отклик (`HapticFeedback.impactOccurred`, `notificationOccurred`).
  - Управление кнопками `MainButton` и `BackButton`.
